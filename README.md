# FemCare AI

A Retrieval-Augmented Generation (RAG) based Menstrual Health Assistant built using:

- Llama 3.2
- LangChain
- FAISS
- Streamlit
- HuggingFace Embeddings

## Features

- Menstrual health chatbot
- Dataset analytics
- Retrieval-Augmented Generation
- Source-aware responses
- Interactive dashboard
